# Changelog

## 0.1.0 — 2026-09-22

Initial source-checkout foundation: synthetic file fixtures, typed read/rename tools, task and resource policy enforcement, durable execution/audit records, local state verification, bounded deterministic mock orchestration, CLI/API, and a connected frontend. Includes initial migrations, tests, CI, and a provisional local 48-issue backlog.

External LLM integration, email/calendar tools, approval/clarification workflows, idempotency-aware recovery, benchmark evaluation, and ML risk detection are not included in this version.
