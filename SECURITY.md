# Security policy

SafeAgent 0.1 is a local synthetic research prototype. It is not intended for production accounts or hostile multi-user hosting. Its process, database, configuration, and local operator are trusted. Read [the threat model](docs/THREAT_MODEL.md) before testing.

Never include credentials or real personal data in reports. After publication, use GitHub private vulnerability reporting if the repository owner has enabled it. The owner must configure a private security contact before wider distribution. Until then, do not post exploit details affecting real systems in public issues.

Ordinary bugs confined to synthetic fixtures can use the bug template. Provide the revision, policy version, test case, observed final state, and expected invariant. No production support SLA or security certification is offered.
