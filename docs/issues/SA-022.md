# SA-022: Implement exact-action approval lifecycle

## Objective

Deliver implement exact-action approval lifecycle as a verifiable part of the SafeAgent specification.

## Scope

Approval requests, single-use grants, expiry, revocation and canonical fingerprints.

## Technical requirements and acceptance criteria

- [ ] Bind approval to canonical action, arguments, resource version and recipients.
- [ ] Reject denied, expired, consumed or modified grants.
- [ ] Allow only the trusted user channel to approve, deny or cancel.
