Milestone: M1 · Priority: P0 · Status: in-progress

## Objective

Deliver complete centralized typed tool metadata as a verifiable part of the SafeAgent specification.

## Scope

Registry metadata and discovery API with explicit callable dispatch.

## Technical requirements and acceptance criteria

- [ ] Register every implemented tool with argument and response schemas.
- [ ] Declare permissions, effects, idempotency, verification and retry metadata.
- [ ] Reject unknown tools and unexpected arguments before dispatch.
